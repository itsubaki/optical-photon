# 光子による量子コンピュータ

ビームスプリッター、位相シフター、理想的な非線形Kerr相互作用によってCNOTを実装する、HTML・CSS・JavaScriptで作成したデモです。
ニールセン＆チャン『Quantum Computation and Quantum Information』7.4節で説明されているdual-rail符号化と光学ゲートを使用しています。

```text
|00⟩_L = |1001⟩
|01⟩_L = |1010⟩
|10⟩_L = |0101⟩
|11⟩_L = |0110⟩
```

4桁の数字は、各経路の光子数を上から順に表します。経路の並びは教科書p.294の配置に従っています。

$$
K(\xi) = \mathrm{diag}(1,1,1,e^{i\xi}), \qquad \xi = \chi L
$$

$$
U(\xi) = (I \otimes H)K(\xi)(I \otimes H)
$$

ξ = πでは、結果が論理CNOTの出力と一致します。入力`|+0⟩`からは、ベル状態`(|00⟩ + |11⟩)/√2`が得られます。
単一光子モードでは、Mach–Zehnder干渉計`B(−θ)P(φ)B(θ)`をシミュレーションします。`P(φ) = diag(1, exp(iφ))`であり、θ = π/4が50:50のビームスプリッターに対応します。
忠実度は、選択した入力と観測点の状態が理想的なCNOTの出力とどの程度一致するかを表すもので、一般的なゲート忠実度ではありません。
損失、光子の識別可能性、検出器の不完全性、状態準備や測定の物理的な装置はモデル化していません。
Kerr相互作用は理想化しています。単一光子間でπの位相シフトを得ることの難しさは、7.4.3節で議論されています。
